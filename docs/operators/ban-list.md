# The ban list for all your servers

If you run more than one server, a ban on one of them already protects the others: the rule **Players banned on your servers** turns away anyone with an active ban from any server of yours. The **Ban list** page in the portal shows that list in one place and lets you manage it.

## What you can do

- **See every active ban** across all your servers, with the server it was recorded on, your own reference for it, the reason you gave, when it was recorded and when it ends. Ended bans (lifted, expired or overturned on appeal) are hidden until you ask for them.
- **Look up a player** by typing their game account id. You only ever see what **you** recorded about them, never what any other owner recorded.
- **Add a ban by hand**, for example after a report on your Discord. Choose the server it is recorded on, the account ids, a reason and, if it is not permanent, how many hours it lasts. It applies to your other servers straight away.
- **Lift a ban** you recorded. A ban that was overturned on appeal ends by itself.

Only the owner of the account can add or lift a ban. Members can look. Adding by hand is limited to 60 an hour.

::: tip The reason is shown to the player
As with bans recorded by the plugin, the reason you type is shown to the player in their own portal. Keep it factual.
:::

## Keeping one server's list to itself

Each server has a switch, **Share bans with my other servers**, on by default. Turn it off for a server that should have its own rules, for example a roleplay server and a racing server that ban for different things. A server with sharing off:

- does not use bans recorded on your other servers, and
- does not give its own bans to your other servers.

Its own bans still protect it. The switch changes only how **your own** servers treat each other. It does not hide a ban from other owners: a ban recorded on a server with sharing off still counts, in the usual way, towards other owners' [rules](/guide/rules).

## What other owners see

Nothing changes for them. The list on this page is yours alone, and nobody else can see it.
